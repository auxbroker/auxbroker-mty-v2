# AUXBROKER MTY Web

Plataforma inmobiliaria diseñada para **Fomentar las alianzas entre asesores inmobiliarios del área metropolitana de Monterrey, Nuevo Leon, gestionar solicitudes, ofrecimientos y seguimientos** de propiedades de manera ágil y organizada.  
Construida con tecnologías web modernas (HTML, CSS, JavaScript) e integrada con **Supabase** para manejo de datos en tiempo real.

---

## 🚀 Lo que ofrece
- Formularios intuitivos para buscar y/o registrar solicitudes y ofrecimientos.
- Módulo de seguimientos y documentación de contactos hechos a asesores.
- Interfaz clara y responsiva, optimizada para uso en escritorio y móvil.
- Estilos modernos y consistentes para una experiencia profesional.

---

## 📂 Estructura simple
- **public/** → páginas principales (index, solicitud, ofrecimiento, seguimientos).  
- **js/** → lógica de negocio y conexión con Supabase.  
- **assets/** → estilos y recursos visuales.   

---

## 🌐 Deploy
El proyecto está listo para ser publicado en **GitHub Pages**, ofreciendo acceso rápido y gratuito desde cualquier dispositivo.
